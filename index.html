📚 Tədqiqat Metodologiyası və Data Mənbələri

SkillMap Azerbaijan platformasında istifadə olunan bütün statistik göstəricilərin, alqoritmlərin və data mənbələrinin rəsmi elmi əsaslandırması.

Əsas İstinad və Məlumat Mənbələri

Riyazi və Alqoritmik Hesablama Modelləri

1. Uyğunluq Faizi (Match Score) Match = (Σ min(U, W) / Σ W) * 100

İstifadəçinin bilik səviyyəsi ($U$) ilə bazarın çəkili tələb indeksinin ($W$) nisbəti.

2. Səriştə Boşluğu (Skill Gap) Gap = Max(0, Tələb - Mövcud_Bilik)

Namizədin vakansiya tələbindən geri qaldığı fərdi səviyyə xalı.

3. Bazar Dəyəri (Salary Predictor) Salary = Base * (0.6 + Match * 0.7)

Bazarın baza əməkhaqqı və namizədin səriştə indeksinin inteqrasiyası.
